# 吉他指板训练器 · Fretboard Trainer

练指板用的小工具，整个应用就是一个 HTML 文件。双击打开就能用，不装环境、不用构建、不用联网。

音阶体系、指型系统、CAGED、琶音、和弦进行、声部连接、即兴素材，全在这一份文件里。

![指板探索 · 自然大调 × CAGED 五型色块分屏](screenshots/01-fretboard-explorer.png)

## 为什么做这个

练琴时最常撞上的三个问题，谱例书和练琴 App 都解决得不太好。

1. **同一个音阶，换个把位就不认识了。** 这多半不是熟练度问题，而是「把位」这个几何概念没吃透。把位是纵向的：从某根弦的某一品出发、逐弦往上铺开的一整条音型，而不是「沿琴颈横向截一段」。
2. **知道音阶，却不知道它能落在什么和弦上。** 音阶和和声很容易变成两张皮。
3. **和弦进行里，相邻两个和弦之间手该往哪走，没人讲。** 很多人一辈子只弹过五个 Barre 位置。

这个工具把这三件事合到同一张指板上：

```
选音阶 → 看它在 9 种指型系统下怎么分块 → 看它的特征和弦与琶音
      → 在具体和弦进行里算出「声部连接最优」的按法 → 给出该把位下能用的即兴素材
```

## 快速开始

不需要 Node，不需要构建，不需要联网，也不用装任何东西。

| 方式 | 步骤 |
|---|---|
| 本地打开（推荐） | 下载 `index.html`，双击即可，断网也能用 |
| 在线使用 | 打开 GitHub Pages 地址（在仓库右侧 About 里） |
| 克隆 | `git clone <本仓库地址>`，然后打开 `index.html` |

所有数据都内嵌在文件里，页面不会发出任何网络请求。你的偏好设置（调性、定弦、主题等）存在浏览器 `localStorage` 里，不会上传。

## 十一个栏目

| 栏目 | 做什么 |
|---|---|
| 🎯 指板探索 | 任选音阶 / 调 / 定弦，在指板上高亮。能切 9 种指型系统、按把位分屏、叠加色块、高亮特征和弦与琶音，还带调式色彩档案和色彩光谱 |
| 🧠 练习模式 | 「找音」是屏幕给一个音名，让你点出指板上它所有位置；「音阶听辨」是听音频判断调式，按 8 个母音阶体系分组出题 |
| 📚 音阶库 | 81 条音阶 / 琶音的总表，按 9 大体系分组。每条给出音级结构、构成音、特征和弦与即兴候选、特点与用法 |
| 🧩 CAGED 和弦 | 同一个和弦在指板上的五个位置。按实际品位从低到高排，所以打头的是哪个型，得看主音是什么 |
| 🧮 音阶和声速查 | 音阶的七级数 × 五层扩展和弦表，点任意一格跳到 CAGED 页看指型 |
| 🎼 琶音探索 | 一个琶音在 CAGED 五个把位上的形状（实心＝本型，白心＝根音，空心圈＝相邻把位的同音），并给出常配的音阶 |
| 🔗 连接训练 | 456 条和弦进行。挑一条，逐音给出声部连接和推荐按法 |
| 🎸 玩点即兴 | 200 首伴奏带。先把和弦进行按小节铺开，再给出声部连接最优的按法，最后列出每个和弦下推荐的即兴素材 |
| 🔍 即兴查询表 | 给一个和弦性质和调性，列出能用的音阶、琶音和替代方案 |
| 🎹 和弦配置 | 把整条进行当成一个整体，搜「声部移动总量最小」的按法组合，给出几个不同的最优解 |
| 🖐 2-1-2 琶音 | 跨弦音数按 2-1-2 交替的琶音指型一览（含只占 3 弦 5 音的基本型），起始弦可在第 6 / 5 / 4 / 3 弦之间切 |

## 几个我比较较真的地方

这些是它跟「随便画几条音阶」的区别，也是每次改版都会回头验一遍的地方。

**母音阶和子音阶（调式）分开放，按级数排。** 音阶库里那 58 条调式不是平铺的，各自挂在所属的母音阶底下，按调式级数排序。听辨出题时勾一个体系，进题库的就是「母音阶 + 它的全部子音阶」；干扰项还会剔掉音级结构相同的音阶，不然题目本身无解。

**把位是纵向的，CAGED 五型在这儿是「位置窗」，不是和弦手型。** 五个型锚在特定弦的根音上，只跟主音走，跟你在弹哪个音阶没关系。显示时按各型实际最低音品升序重排，所以最左边永远是品位最低的那个型，相邻型间距固定是 3、2、3、2、2 品。贝斯族没有 CAGED 体系，会退回骨架指型。

**吉他的「邻近」得按品位几何算，不能按音高差算。** 同一个音高在指板上有好几个落点：`2 弦 5 品 → 1 弦空弦`，音高一动不动，手却要从 5 品挪回 0 品。只看半音，就会挑出「A7 在第 12 品、E7 在第 7 品」这种看着近、其实要跳半个指板的连接。所以声部连接的代价是这么算的：

```
代价 = Σ[ |Δ品| + 0.35 × |Δ半音 − Δ品| ]   同弦时品位变化就是音高变化，不重复计量；
                                            跨弦时多出来的那一截才算「换弦费」
     + 1.0 × |整只手位中心的位移|            这一项省不得，省了就会挑出
                                            「每根手指只挪一点、整只手左右横跳」的按法
     + 3.4 × 声部数不齐的个数
```

拿 100 首伴奏带、1000 个相邻和弦对实测：手位移动中位数 0.5 品，最大 2.0 品。

**谱上怎么按，手上就在哪个把位即兴。** 玩点即兴页里，和弦卡的角标、素材表的「本方案把位」列、指板图的标题，取的是同一个把位窗口变量，三处数字必须对得上。这个能写回归测试直接验。

## 技术说明

- **单文件**：整个应用（HTML + CSS + JS）就是 `index.html` 一个文件，9,271 行 / 654 KB。没有构建步骤，没有依赖，也没有 CDN。
- **零外部请求**：没有 `<link>`、没有 `fetch`、没有 `XMLHttpRequest`、没有动态 `import()`。文件里唯一出现 URL 的地方是 SVG 的命名空间标识符，不产生网络访问。
- **声音是实时合成的**：用 Web Audio 的三角波叠锯齿波合成音高，仓库里不含任何音频文件。
- **数据全部内嵌**：音阶、定弦、和弦进行、伴奏带、素材表都是 JS 字面量，没有后端。
- **渲染**：指板图是 JS 现算的 SVG，不是位图，放到多大都清晰，也能直接打印。
- **主题**：浅色 / 暗色两套，靠 CSS 变量切。
- **状态持久化**：偏好设置写 `localStorage`，只存在本机。

## 用之前要知道的

- 只覆盖 6 弦吉他、7 弦吉他、4 弦贝斯、5 弦贝斯。其他弦数，或者不是十二平均律的乐器，不在范围内。
- 声部连接用的是品位几何近似，不模拟生理上的指法限制。比如同一根手指能不能同时够到两处，它不检查。
- 「推荐即兴素材」是照和弦性质与调式匹配出来的，是一个能用的集合，不是唯一正确答案。真弹起来，更取决于你想听什么。
- 有些伴奏带在原素材里只给了整首的音阶选项，没有逐和弦的。这种情况素材表会退回整首通用项，并用虚线徽章标出来，不会假装它有专属选项。
