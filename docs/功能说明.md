按栏目逐个说明**怎么用**和**该看哪里**。建议先读「顶栏与全局设置」，其余按需跳。

## 顶栏与全局设置

顶栏从左到右是全局状态，改动会立刻影响所有栏目：

| 控件 | 说明 |
|---|---|
| **调性** | 当前主音（C、C#、D …）。几乎所有计算都从它出发 |
| **定弦** | 19 种预设：6 弦吉他 11 种、7 弦吉他 6 种、4 弦贝斯 1 种、5 弦贝斯 1 种。切到 7 弦 / 贝斯时，指板宽度、声部数、可用指型都会跟着变 |
| **音阶** | 快速切换当前音阶（与「指板探索」左栏联动） |
| **播放 / 下行 / 停止** | 用合成音把当前音阶弹出来。「上行」按音高升序，「下行」反向 |
| **声音 / 主题** | 静音开关；浅色 / 暗色主题 |

> **音符播放是实时合成的**（Web Audio 振荡器），不是采样音频 —— 所以文件里没有任何音频素材。

## 🎯 指板探索

主界面。左栏是控制，右栏是指板图。

**顺序建议：**

1. **选音阶** —— 左栏「分类」先挑体系（自然大调 / 和声小调 / 五声·布鲁斯 …），再挑具体音阶。
   调式是挂在母音阶下的，所以「多利亚」在「自然大调体系」里能找到。
2. **选指型方式** —— 这是本页最核心的开关。指型下拉共 **10 种**系统，
   其中「宽指型」与「一弦四音」**同一时刻只出现一个**（**五声 / 布鲁斯族**下前者顶替后者，见下）：

   | 指型 | 含义 |
   |---|---|
   | 不分区 | 整条音阶一块显示，不分块 |
   | 一弦三音 3NPS | 每根弦恰好 3 个音阶音，最经典的重金属 / 速弹指型 |
   | 一弦四音 4NPS | 每弦 4 音，把位更宽、换把更少（五声 / 布鲁斯族下不出现，换成下面的宽指型） |
   | 宽指型（本把位 7 品窗全取 · 一弦 3–4 音） | **五声 / 布鲁斯族专用**（大调 / 小调 / 属五声、埃及音阶、平调子 / 阴旋法 / 云井调、五声调式 3・4 型，以及布鲁斯 / 大调布鲁斯 / 小调六声）：一块 = **一个 7 品把位窗里、每根弦上的全部音阶音**（见下） |
   | 3-1-3 跨弦 | 跨弦音数按 `3-1-3-1-4`，5 弦共 12 音；最高弦 4 音（换把靠它咬合） |
   | 2-1-2 琶音 两八度 | 跨弦 `2-1-2-1-2-1`，最多 6 弦 9 音；块内取音是**三度叠置**，不是连续音阶音 |
   | 2-1-2 基本型 | 只占 3 弦 5 音的最小单元 |
   | 一弦二音（五声型） | 每弦 2 音，五声 / 布鲁斯的专用分块 |
   | CAGED 五型色块 | 五个**位置窗**（见下）；在「指板练习」里按**整条琴颈的全部落位**铺 —— 同一型在低把位与高把位各算一处（标准定弦下五型共 **10** 处） |
   | 把位窗（每 3 品一窗） | 按品位硬切，用来对照把位与指型的差别 |

   **所有跨弦指型共用一条换弦选音规则**（对任何定弦都成立，开放调弦不例外）：

   - 一整条指型横向限定在一个 **7 品窗**内；
   - 取音数为 1 的那根弦（3-1-3 的两个「1」、2-1-2 的「1」）优先落在
     窗内 **+1 / +2 品**，也就是**中指 / 无名指**上；
   - 两条豁免：**一弦四音 4NPS** 与**五声族音阶** —— 它们一条弦就要跑满半个把位，
     7 品窗天然装不下（但换成「宽指型」的那一档**自己就是按 7 品窗定的**，见下）。
   - **五声 / 布鲁斯族的 4NPS 换成「宽指型」**（第 44 轮覆盖 9 条 5 音五声、
     第 45 轮覆盖 3 条 6 音布鲁斯族，全族 12 条）：这一族的 4NPS（每弦 4 音 × 6 弦 = 24 音）
     在标准定弦上一块都画不出来，档位因此换掉。
     - **一块 = 一个 7 品把位窗里、每根弦上的全部音阶音**（第 46 轮定稿）：窗取
       `[锚点品 − d, 锚点品 − d + 6]`，`d` 取**最小的、让每根弦都至少有 3 个音阶音**的值
       （最多让 4 品）；让不到就取「完整弦数最多」的那个窗，尽量而为。
     - 于是 5 音音阶一弦正好 3 个音（看着像一弦三音），6 音的布鲁斯族一弦 3–4 个音 ——
       **窗里本来就有的第 4 个音留着，不砍**。
     - 它比 2NPS（五声型）横向铺得更开，是摆脱「五个盒子」的一种练法。
       选音阶时这一档会自动换过来，页面的指型提示行会写明窗是怎么让的。
   - 七弦定弦下的 **3NPS / 4NPS 铺满 1–7 弦**：不再按 6 弦骨架切成「2–7 弦组 / 1–6 弦组」两组，
     只出一组。代价是跑句更长（4NPS 窗宽到 17–19 品，它本来就在豁免档里）；
     7弦 C# 定弦（`C#F#BEG#C#C#`）弦距只跨 2 个八度，4NPS 在 24 品内铺不出来，会提示放不下。
   - **Bebop 三兄弟（大比博普 / 多利亚比博普 / 属比博普）另有一套编排**：它们比各自的母音阶
     多**一颗经过音**、共 8 个音，指型**不能**按这 8 个音重排 —— 那样会把母音阶的 7 个把位
     与手型一起丢掉。改为**以母音阶的对应指型为骨架，再把落在本把位品窗内的经过音点缀进去**：
     它紧跟在**下方邻音**之后弹（大比博普的 `5`、多利亚比博普的 `b3`、属比博普的 `b7`，
     恰好都是和弦音）。所以它们的**把位数量与母音阶完全一致**；
     骨架里没有那颗下邻音的块（音数少的 2-1-2 型常见）就**不点缀**。
     选到这三条音阶时，指型提示行与音阶描述里都会写明这一点。

   —— 所以「用哪套形状」（上表）和「形状落在哪一档」现在是两件事：
   前者仍是固定的跨弦音数，后者由规则现算，**不再随定弦漂移，也不再靠手工参数错位**。

3. **按把位分屏** —— 打开后「一个指型一张图」，各自独立成图；关闭则是一条长指板。
   练习建议：**先看分屏图建立肌肉记忆**，再关掉分屏在整条指板上找位置。
4. **显示指型色块** —— 把每个块染成不同颜色，图例在下方。这是理解「块与块如何咬合」的关键。
5. **高亮特征和弦琶音** —— 只显示当前音阶特征和弦的构成音，其余音灰掉。
   关掉则显示音阶全部构成音。**这是「知道音阶」到「知道用在哪」的桥**。
6. **标记内容** —— 音名 / 简谱 / 唱名 / 音级 / 无。「按音级着色」打开时，同一个音级在任何调里颜色一致，
   很适合找规律。

**右栏下方还有两张卡：**

- **特征和弦 · 琶音属性**：当前音阶的特征和弦、琶音类型与一个可以试听的琶音。
- **调式色彩光谱**：把这个音阶的「明亮 ↔ 阴暗」程度放在一条光谱上，并给出与它最接近的音阶。
  挑音阶时很有用 —— 想要「更亮一点」就往右挑。

## 🎵 指板练习

把「模进练习」做成可以**逐块定制**的一页：选音阶 → 挑具体的把位块 → 给每块指定走法。

**位置是一块一块选的。** 一块 = 通用把位分支的一个把位 / CAGED 的一份落位 / 三品窗的一段
（直接复用指板探索那套 `buildBlocks` 的块，不另造坐标）。全指板（0–24 品）下：五声 / 布鲁斯族
**81** 处、六声族 **94** 处、七 / 八声族各 **107** 处（换成 0–12 品则依次 70 / 71 / 93 / 95）；
只列与当前品段相交的位置。

**CAGED 栏专门细化到每个把位。** 五个型在整条琴颈上各会落到 **2** 个把位（低把位 + 高把位，
标准定弦下五型共 **10** 处；实测 17 条吉他定弦 × 12 个主音、**204** 组，每组恒 10 处、
每个型恒 2 处，没有例外）—— 只写一个型名点不准是哪一个。所以这一栏：

- **按型分行**：`C 型 / A 型 / G 型 / E 型 / D 型`，行序 = 该调下窗底最低的型排最前
  （C 调是 C→A→G→E→D，G 调就转成 G→E→D→C→A）；**与当前品段相交的型全部列出** ——
  常选的 0–12 品与全指板下五个型一个不缺；
- **行内按品从低到高**列出该型的每一个具体把位（如 A 型：`2–6` 与 `14–18`）；
- 行末的「全选」**只管自己这一行**（「这个型的高低把位一起练」一键搞定），不会漏到别的型；
- 顺序槽与摘要行写**完整名字**（`CAGED A 2–6 品`），不会只剩一个「2–6 品」看不出是哪个型。

**「练习位置」有两种模式：**

- **跟随指型** —— 走当前指型系统的全部把位；
- **自定义** —— 点「选择位置…」展开面板，点方块加入练习顺序（可多选、**可跨指型系统混选**），
  拖顺序槽调次第。面板上「全部可见 / 清空 / 收起」，底下「段序」两档可切
  （**按品序** / **按练习顺序**），按「✓ 完成选择」生效。摘要行随时显示选了几处。

**练习级别 L0–L4：** 逐音 / 二音组 / 三音组 / 四音组 / 套嵌，另加模进布局与音序 σ。
三音组（L2）是枚举能力最强的一档 —— 长度 ≤ 4 个音的走句里它能给出 8 种音序，四音组只有 6 种。
三音琶音遇上 L3（k=4）时会**就地降到 k=3**（否则铺不出布局、走句变 0 音），页头提示里会写明实际档位。

**按定弦切两套组织逻辑** —— 同一条音阶在两种定弦下编排出不同的走句：

| 定弦 | 组织逻辑 |
| --- | --- |
| 6 / 7 弦纯四度、标准调弦、全降半音 / 全降全音 | **音程关系为主，位置关系为辅** |
| 其他开放调弦（DADGAD / Open G / Open D / FACGCE / DAEAC#E / CGDGBD…） | **按把位逻辑**优化 |

**逐块串行走句。** 一个把位块整条走完才换下一块。每块的方向有两个入口：

1. **指板图下方每个块都有一个按钮** —— 点一下换下一档（8 档循环）；
2. **在指板图上右键那一块** —— 八档菜单任选，还能「全部同此」。

**八档走法：**

| 档位 | 走到哪、怎么收 | 末音落在 |
| --- | --- | --- |
| ↑ 上行右连接 | 走到最高音弦的最高音就收住（＝原来的「上行」） | 右上角 |
| ↖ 上行左连接 | 升到顶后**在最高音弦上折回** | **最高音弦的最低音** —— 接左边（低把位）那一块 |
| ↓ 下行左连接 | 走到最低音弦的最低音就收住（＝原来的「下行」） | 左下角 |
| ↘ 下行右连接 | 到底后**在最低音弦上折回** | **最低音弦的最高音** —— 接右边（高把位）那一块 |
| ↕ 上下行 | 上行到顶后原路折回 | 顶点 |
| ⇵ 下上行 | 上下行的镜像：先倒着走到最低音，再原路回到最高音 | 顶点 |
| ⇅ 智能决定 | 按下一块的位置自动挑上行还是下行 | —— |
| ↝ 跟随工具条 | 跟随工具条上那一个全局方向 | —— |

按钮副标上「收在 X 弦 Y 品」写的就是这一块走句**真正的末音**。

**换把区自动标注** —— 选中的多块之间，指板图上会把「上一块结束、下一块开始」的那一段品标出来。

**跟随模式下有一条指型回退链**：3NPS → CAGED → 宽指型 → 4NPS。少数「定弦 × 音阶」组合
铺不出某一种指型的块（例如 7 弦 C# 定弦上的 3NPS），这时自动换到下一个铺得出来的，
并把**实际用的是哪一种**写在页头提示里。**自定义模式不走回退链** —— 你点的是具体的块，缺了就如实说缺。

上排工具条：**▶ 播放模进** / **■ 停止** / **🔁 循环** / 方向 / 时值 / **☐ 音名** / **☐ 专注模式**，
右侧一行统计（共 N 音 · M 个三音组单元 + K 段连接 · P 个选中位置）。

**☑ 专注模式**（默认关）—— 开着时指板图上**只留下正在走的那一块指型的音**，其余音全部隐掉，
一块一块地看，别的位置先不干扰。焦点跟着播放换（也可以右键切块），图下方那条**逐块方向条**上
当前那一块会被描边高亮，勾选框右边的小字写明「只看第 N 块 · 标签（X–Y 品）」。关掉开关立刻恢复全部音。
来回切**不重置焦点**，视角不会跳；实现上只给非当前块的音符打一个隐藏类、**不重画整块** ——
正在跑的播放定时器、谱面高亮与工具条都不受影响。

**谱面装进独立视窗。** 指板图下方的 TAB 与五线谱不再整幅铺开，而是进一个**自己的视窗**
（默认 520 × 520，长宽各自可调），自己滚自己的。视窗上沿多一条工具条：

| 控件 | 取值 | 做什么 |
| --- | --- | --- |
| 视窗 / 通栏 | 二选一 | 「通栏」= 原来的整幅排版，给不喜欢视窗框的人留的退路 |
| 缩放 | 50–300%，默认 100% | ≤ 100% 恒铺满视窗宽（100% = 一行正好铺满）；> 100% 整块放大、超宽横滚 |
| 适应宽度 | 按钮 | 一步回到 100%（从放大状态复位） |
| 宽 | 320–1000 px，默认 520 | 视窗宽度 |
| 高 | 260–1000 px，默认 520 | 视窗高度，与宽**各自独立** |
| 正方形 | 按钮 | 高 = 宽（一步回到第 79 轮的方形观感） |
| 每行 | 21 / 22 / 23 / 24，默认 24 | 谱子每行放几个音 |
| ☑ 谱子跟进 | 默认开 | 播放时视窗自动跟到当前音 |

- **视窗长宽只改一个 CSS 变量**（`--psv` / `--psvh`），**不重绘** —— 视窗多大与谱子怎么排无关
  （谱子恒铺满内宽）。**缩放**在 ≤ 100% 时要重排谱子（行宽跟着放宽），但**不是整块重绘**：
  只换谱子那一块 `.ps`，工具条与正在拖的滑块原样不动，所以拖起来仍是连续的（见 `fpReflow`）。
- **100% 的基数是「视窗内宽」**，不是绝对像素。24 个音一行自然宽约 1283 px，方形视窗只有 520 px ——
  拿绝对像素当 100% 的话一进场就只看得见三分之一行，非先点一次「适应宽度」不可。
  改成百分比之后默认视图直接是一整行，而且视窗尺寸改了它自动跟着变。
- **但元素宽本身不能再跟着缩放走**：svg 的 `viewBox` 恒等于内容宽，元素宽写成 `100% × z` 就等于
  「缩得越小、右边留白越多」（70% 时只占七成宽）。所以 ≤ 100% 时元素**恒为 100%**，
  「变小」改由**行宽顶宽**承担 —— 一个 `stretch` 系数乘在每个音的横向步进上，
  由 `σ = 1 + rowW·(1/z − 1)/(n·step)` 精确解出。σ ≥ 1 恒成立，音符只被排开、绝不会挤到一起。
- **每行的切法**：上限 21–24，按**均分**切行（各行最多差 1 个音，不会出现「24 + 16」这种一头沉）。
  其余页面的谱子不受影响，仍按 18 切 —— 这一档只作用于本页。
- **谱子跟进分两轴**：纵向按**行**判（一行进不全就把这行顶到视窗顶部）；横向按**当前音**判，
  只在它真的探到边（留 20 px 余量）时才把它挪回视窗正中。100% 时两轴都不动；放大到 200%
  才会隔几拍挪一次 —— 视窗不会每一拍都晃，眼睛可以一直留在指板图上。
- 「每行」改了会**重排谱面**（行数变了），所以那一档走整块重绘；**缩放**也要重排（行宽变了），
  但只换谱子那一块 `.ps`；**视窗长宽**完全不重排。
- **长宽是各自独立的两个量**：高用显式 `height`，不是 `aspect-ratio` —— 后者只能保持比例。
  高度也不受 `min(…, 100%)` 那种夹取（CSS 里没有 `max-height`），所以「高 1000」在任何窗口宽下都是 1000；
  宽度会被所在栏的内宽夹住，那是「不顶宽整页」的设计。

## 🎼 指型谱：每个指板图都带 TAB 与五线谱

除「不分区」模式外，**每一个显示的指板图下方**都会附一条指型谱：先 **TAB**，再**五线谱**。

- **TAB 类型跟「乐器 + 定弦」走**：吉他用六线 / 七线 TAB，贝斯用四线 / 五线 TAB；
  五线谱的谱表同样自动分派 —— 吉他高音谱表，贝斯低音谱表（F 谱号）。19 条定弦逐一核查通过。
- **走句来源就是这块指型本身**：按「先弦后品」从最低音弦的最低音走到最高音弦的最高音；
  方向可选**上行 / 下行 / 上下行**。
- **长走句自动分页**：每行最多 **18 个音**，并且**均分**（各行最多差 1 个音）。
  分页界限只由这一条决定，与版面、乐器、定弦都无关 —— 一块再长也不会被压扁到看不清。
  （「指板练习」页的谱子进了方形视窗，那一页每行可调 **21–24** 个音，见上一节。）
- **播放与跟练**：**▶ 播放**按谱面音高依次放一遍，一个音的间隔 = 时值(拍) × 60 / BPM，
  与左下角的节拍器同源；**🔁 循环**播到最后自动从头再来。
- **播到哪一颗就只亮哪一颗**：指板图上点亮的是**走句里这个音自己记着的那一个位置**
  （弦 + 品唯一确定一个音位）—— 不是把同音高的位置全点亮，所以跟谱时看得出手该按哪根弦哪个品。
  该位置这一帧恰好没画出来时（品段裁掉、分屏不在本窗），退回升到按音高找，不留「什么都没亮」的空拍。

## 🎧 视听练习

七种题型，用「选择题型」切换：**指板认音 · 音阶填空 · 听音辨名 · 音程听辨 · 音阶听辨 · 五线谱视奏练习 · 简谱视奏练习**。

### 找音（指板认音）

屏幕给一个音名，在指板上把它**所有**位置都点出来（范围由「指板范围」决定）。
点对 +10 分并累计连击，点错 −6 分且连击清零。

练的是「看见位置就知道是什么音」的条件反射。**建议先在小范围（0–4 品）刷满，再逐步扩大。**

### 音阶填空

指板上把某条音阶的**参考音铺出来**，其中**挖掉几个位置**，要你把缺失的音点出来。

- **参考音默认就给**（它是做题的依据），**待填的位置默认没有任何标记** —— 得自己按音阶结构推。
  以前反过来：参考音要点了「提示」才铺、待填位置却先被圈好，对着圈点就能答，等于把答案漏了。
- **💡 提示** 只管一件事：**把待填的位置标出来**。它是两态开关，可以来回切；
  开或关，**参考音一个都不变**。
- 题目**不改写全局状态**：出题时临时用到的调性、存档与探索页状态都收回题内，
  换题 / 停局不会污染顶栏调性与本机偏好。
- 目标音按当前**弦组**过滤 —— 不会出现「要你点的音根本不在显示的弦上」。
- 「已显示的音阶音」不算答对；可填位置数按实际可点位置收敛，不顶穿。
- **「指板范围」在本页就能改**（与「指板探索」「指板练习」共用同一份设置、双向同步）。
  练习途中换品段会**作废当前题并重出一题** —— 旧题记的是「弦 + 品」坐标，按新范围算会自相矛盾。

### 音阶听辨

播放一段音阶，判断是哪个调式。题库按 **8 组母音阶体系**分组勾选：

> 自然大调体系 · 和声小调体系 · 旋律小调体系 · 和声大调体系 · 双和声小调体系 · 五声 / 布鲁斯 · 对称音阶 · 异域 / Bebop

勾一个体系 = 「母音阶 + 它全部的子音阶（调式）」一起进题库。
**干扰项会自动剔掉音级结构相同的音阶** —— 否则题目无解（比如两个音阶音程结构完全一样时，光靠听根本分不出）。
答完揭晓的是**体系名**，不是母音阶名。

### 五线谱视奏练习

按**母音阶组**出题：勾一个体系 = 「母音阶 + 它全部的子音阶（调式）」一起进题库
（与「音阶听辨」共用那 8 组分组）。

题目画成**五线谱**，带**调号**与**节奏** —— 时值、符干、符尾、附点、休止符
都按真实记谱画，一小节一小节排下去，收尾给一条终止小节线。
长度在左侧「每题音符数」自己定：3–12 个，默认 5。
出题时只在**当前指板范围里点得出来的音**中走句 —— 所以题目一定点得出来；
范围收窄到装不下整条音阶时，题板会明写一句提示，不静默少音。

**谱表跟定弦自动走** —— 顶栏定弦选的是吉他还是贝斯，决定题目画在哪张谱上：

| 定弦 | 谱表 | 记谱 |
| --- | --- | --- |
| 吉他（6 / 7 弦，含各种开放定弦） | **高音谱表**（G 谱号） | 谱面 = 发声 + 12（吉他习惯） |
| 贝斯 4 弦 EADG / 贝斯 5 弦 BEADG | **低音谱表**（F 谱号） | 谱面 = 发声 + 12（贝斯谱惯例） |

两边都是「谱上的音比实际发音高一个八度」，但**两套口径各写各的** —— 换个谱表不影响另一边。
不用手动切谱表；**同一族内换定弦**（4 弦 ↔ 5 弦）保持当前题，**跨族换定弦**自动换一题
（旧题的音在新定弦上可能根本点不出来）。

**贝斯题只在低音谱表的常用音域里走句** —— 谱位限制在**加线不超过 3 条**那一段
（谱位 12–32，约等于实际发声 A0–G3）：下限由定弦本身决定（4 弦空弦 E1、5 弦空弦 B0），
上限落在 G 弦 12 品。贝斯若按指板范围直走到 24 品，谱面会拖出七八条加线，那样的谱没法读。

**调号怎么给：** 七声调式按所属大调给调号（D 爱奥尼亚 → 两个升号）；
五声 / 布鲁斯这类没有标准调号的，按「临时记号最少」挑一个，实在不合适就不给调号，
音阶外的音一律写成临时记号。调号里各记号的谱位按所用谱表排（真谱怎么排就怎么排）。

**怎么弹：**

1. **读谱**，然后按谱面顺序在指板上依次点出来。点一下，**同音高的位置会全部亮起来** ——
   亮起来的一片就是这个音高在琴颈上的所有落点，环色用的是该音高类的专用色
   （与「和弦查询」同一套 12 色，一眼能跟左边的已选音对上）。
2. 指板图下方实时记一行**你的作答**（已点的音，带序号），旁边是按钮行。
3. 点错了按 **↶ 撤回上一步**；想整条重来按**清空作答**；点满后按 **✅ 提交答案**。
4. 卡住了：**▶ 试听题目**按谱面音高依次放一遍（休止符只占时间不出声）；
   **☐ 显示音名**（**默认关**）把每个音的音名标在谱下（例如 `F#4`）—— 两个都当读谱辅助用。
   标注的是**谱面音名**（= 记谱音高），所以贝斯题上写的是比实际发音高一个八度的那个名字。

**判定卡八度** —— 谱面写的是哪个音高就点出那个音高：同一个音高换个把位算对
（吉他 1 弦空弦和 2 弦 5 品都是 E4；贝斯 E 弦空弦和 A 弦 5 品都是 E1），点成别的八度算错。
全对自动进下一题并加分；有错则谱面上那几颗标红叉、扣 6 分并**停在本题**，撤回改对再提交即可。
勾选的母音阶组、每题音符数与音名开关都会存进本机偏好。

### 简谱视奏练习

上一节同一件事的另一种读法：题目画成**简谱** —— 首调数字 + 高低音点 + 升降号 + 时值记号 + 小节线，
读谱之后在指板上**按顺序**点出对应的音。

**节奏与五线谱视奏完全同一套** —— 同一份出题槽位（拍号 3/4 或 4/4、槽位一小节一小节铺满、句尾补休止），
时值也是同一组：

| 时值 | 简谱怎么写 |
| --- | --- |
| 八分音符 | 数字下加一条下划线 |
| 四分音符 | 数字本身 |
| 附点四分 | 数字后加附点 |
| 二分音符 | 数字 + 一条增时线「−」（就是一横） |
| 全音符 | 数字 + 三条增时线 |

休止符一律写 `0`，时值记号同上。小节线由累计拍数决定，与五线谱同一判据。

**「1 落在哪」是简谱的灵魂**，所以题板左上角直接把调号写出来（`1 = X`）：

| 体系 | 母音阶（首调） | `1` 落在 |
| --- | --- | --- |
| 自然大调体系 | `1234567` | 该调主音 |
| 和声小调体系 | `671234#5` | **关系大调的主音** |
| 旋律小调体系 · 1 = la | `12b34567` | 该调主音 |
| 旋律小调体系 · 1 = do | `67123#4#5` | **关系大调的主音** |
| 和声大调体系 | `12345b67` | 该调主音 |
| 双和声小调体系 | `671#234#5` | **关系大调的主音** |

> 三支小调体系本来都按「关系大调主音为 1」写（所以是 `6 7 1 …` 起头），
> **旋律小调（第 72 轮起）两套都留、占两行**：`12b34567`（1 = la，以自身主音为 1）
> 与 `67123#4#5`（1 = do，以关系大调主音为 1）。这是**有意**的 ——
> 前者一眼看出「上行还原了 6 / 7 级」，后者才看得出「就是大调降低三级」（第 3 级记 `b3`）。
> 同一个音阶按两种读法各列一条，出题时**分别成题**，勾选互不影响。
> ⚠️ 「1 = X」一律读作**「数字 1 记在 X 这个音上」**，不读作「X 是主音」。

**子音阶一律按首调记**：母音阶的基串**循环左移**就得到下一级调式的写法。
以自然大调为例 —— `1234567` → 多利亚 `2345671` → 弗里吉亚 `3456712` → 利底亚 `4567123`
→ 混合利底亚 `5671234` → 自然小调 `6712345` → 洛克里亚 `7123456`。
其余五个体系实例同理，各 7 条 —— 六条体系实例一共 **42 条**（旋律小调两套记谱法各 7 条）：

- **和声小调体系**：和声小调 `671234#5` · 洛克里亚 ♮6 `71234#56` · 伊奥尼亚增 `1234#567` ·
  多利亚 #4 `234#5671` · 弗里吉亚属（西班牙音阶）`34#56712` · 利底亚 #2 `4#567123` ·
  超级洛克里亚（♭♭7）`#5671234`
- **旋律小调体系 · 1 = la**：旋律小调 `12b34567` · 多利亚 ♭2 `2b345671` · 利底亚增 `b3456712` ·
  利底亚属（变化利底亚）`456712b3` · 混合利底亚 ♭6 `56712b34` · 洛克里亚 ♮2 `6712b345` ·
  变化音阶 `712b3456`
- **旋律小调体系 · 1 = do**：旋律小调 `67123#4#5` · 多利亚 ♭2 `7123#4#56` · 利底亚增 `123#4#567` ·
  利底亚属（变化利底亚）`23#4#5671` · 混合利底亚 ♭6 `3#4#56712` · 洛克里亚 ♮2 `#4#567123` ·
  变化音阶 `#567123#4`
- **和声大调体系**：和声大调 `12345b67` · 多利亚 ♭5 `2345b671` · 弗里吉亚 ♭4 `345b6712` ·
  利底亚 ♭3 `45b67123` · 混合利底亚 ♭2 `5b671234` · 利底亚 #2 #5 `b6712345` ·
  洛克里亚 ♭♭7 `712345b6`
- **双和声小调体系**：双和声小调（匈牙利小调）`671#234#5` · 2 型（东方调式）`71#234#56` ·
  3 型（伊奥尼亚 #2 #5）`1#234#567` · 4 型（洛克里亚 ♭♭3 ♭♭7）`#234#5671` ·
  5 型（＝双和声大调 / 拜占庭）`34#5671#2` · 6 型（＝双和声大调的第 2 调式）`4#5671#23` ·
  7 型（超级弗里吉亚）`#5671#234`

**两级勾选**：体系那一级只管「全选 / 全不选」，真正的出题库是**子音阶那一级** ——
某个体系只勾了一部分时，那一行显示成**半选**（既不是实勾也不是空）。
把子音阶全部取消会自动回落成六条体系实例全选（42 条，不会变成一道题都出不来）。
每题音符数同样 3–12，默认 5。

**其余一律与五线谱视奏相同** —— 这不是巧合，两边共用同一套作答与判定：

- 点一下，**同音高的位置全部亮起**，顺便看清这个音在琴颈上的所有落点；
- **判定卡八度**：题目要的是哪个音高就点那个音高，换个把位算对，点成别的八度算错；
- **▶ 试听题目**（休止符只占时间不出声）、**☐ 显示音名**（**默认关**，要看得自己打开）
  —— 这里标的是**实际发音的音名**（简谱没有谱表八度这回事，不像五线谱那边标的是谱面音名）；
- **作答牌子上写的也是实际发音的音名** —— 与题目简谱的高低音点、谱下音名**同一个八度**。
  （五线谱那条的牌子跟谱面走、比实发高一个八度；两条口径各自自洽、不能混 ——
  混了就会出现「牌子上写着 E4、题目要的却是 E3」这种局面。）
- **提交后每个音的对错直接标在谱面上**：对的在数字右上角打一个绿勾，错的用红叉压在数字右半边
  （左半边仍然读得出来）—— 判完不用再逐个回忆「我点的是哪一个」；
- **↶ 撤回上一步** / **清空作答** / **✅ 提交答案**，全对自动进下一题。

**简谱不跟着定弦换谱表**（它本来就没有谱表）。但题目算的是「弦 + 品」坐标，
所以**改定弦 / 改品段一样会作废当前题**（与填空、五线谱视奏同一套口径）。
勾选集、音符数与音名开关都存进本机偏好；**「数字下标注音名」默认关**（与五线谱视奏那边同一个默认，两处对齐）。

## 🧩 CAGED 和弦

同一个和弦在指板上的 5 个位置，串联起来覆盖整条指板。

**关键点：这里的 CAGED 五型是「位置窗」，不是和弦手型。**

- 每个型锚在某根弦的根音上：A 型锚第 5 弦、G 型锚第 3 弦、E 型锚第 6 弦、D 型锚第 4 弦、C 型锚第 2 弦。
- 窗口 = `[根音品 − 1, 根音品 + 3]`，只跟**主音**走，与音阶无关。
- 因此本页按**实际最低音品升序**排列：选 C 调是 C 型落在空弦位、选 G 调是 G 型落在空弦位
  （就是那个开放 G 和弦的位置）、选 A 调从 A 型起。**打头的是哪个型随主音变，这是刻意的。**
- 贝斯族没有 CAGED 体系，会退回骨架指型。
- 顶部「**变调夹**」可夹 1–9 品（默认不夹）。夹在第 N 品等于**琴枕上移 N 品**，所以本页摆的是
  「根音降 N 个半音」那个型的落位；格子里的品位数字与把位标记**一律相对变调夹**写
  （0 = 就在夹子处按弦），卡片上另标一行「实际弹在第 X–Y 品」。
  例：主音 C 夹 2 品，五张图是 **B♭ 型的落位**，实际发出来仍是 C 大三和弦 ——
  这就是变调夹的用法，换一个更好按的手型弹同一个和弦。

页面下方还有一张「CAGED 与音阶的对应」说明，讲清每个型覆盖哪些品、怎么把五个型串起来。

## 🎸 玩点即兴

200 首伴奏带。每首给出三层信息，**从「弹什么和弦」到「在这个把位弹什么」**：

1. **和弦进行** —— 按小节铺开，上面是小节号、中间是和弦记号、下面是对应的级数。
2. **声部连接 · 最优按法** —— 把整条进行当作一个整体，搜索「声部移动总量最小」的按法组合，
   给出 3 个方案（全局最优 / 低把位 / 中把位等）。每个和弦卡上标注**相邻两处手挪了几品**。
3. **每个和弦下推荐的即兴素材** —— 按和弦归堆，并给出**本方案把位**这一列。
   没有专属素材的和弦会回退到「整首通用」项，用**虚线徽章**标出（不假装它有专属选项）。
4. **高频素材 · 把位指板图** —— ★ 标记的高频素材另外配一张指板图，**把位取该和弦该方案用的同一个窗口**，
   所以「谱上怎么按，手上就在哪个把位即兴」。标题里会写明 `把位第 A–B 品（= 该和弦按法所在窗口）`。

**验证一致性**：和弦卡角标、素材表「本方案把位」列、指板图标题这三处的数字必须相同 —— 它们取的是同一个变量。

## 🎹 和弦配置

一条和弦进行，两种模式 —— **目标不同，别混着看**：

- **声部连接最优**（默认）—— 把整条进行当作整体，搜索「声部移动总量最小」的按法组合，
  给出几个不同的最优解（低 / 中 / 高把位区各一个）。
  - 6 / 7 弦吉他按 4–5 声部；4 / 5 弦贝斯按 3–5 声部（shell voicing 也一起枚举）
  - 方案卡上给出：整条进行手位一共挪了多少品、各声部音高合计移动多少半音、按品平均位置
- **最常见 / 最易按** —— **逐和弦独立**，不做任何跨和弦配对，等价于翻一本和弦表：
  每个和弦各挑各的，取教材和弦表上那一个按法（C = `x32010`、Dm = `xx0231`、
  G7 = `320001`、Cmaj7 = `x32000`…）。
  - 成本按教材口径**分档**算，重的档在前：
    - ① **第一把位优先**（1–4 品；按品超过 4 品后每高 1 品重罚）
    - ② **弦组不许挖空**（闷弦只允许出现在低音侧 —— `x32010` / `xx0232` 是常规写法）
    - ③ **以「品」为单位数手指**（同一品的相邻弦算一根，横按不额外罚分）
    - ④ **手指不许被顶开**（同一品被更低的音或空弦切成两段就扣分）
    - ⑤ **空弦奖励**（不用按的弦直接省一根手指）
    - ⑥ **低音落在最低那根弦 / 第二根弦**（CAGED 的 E 型 / A 型）额外加分
    - ⑦ 跨度 4 品以内、弦组连成一片、手位尽量低
  - 声部下限与模式一**一致**（吉他 4 声部起、贝斯 3 声部起），上限放开到把弦按满 ——
    教材上的开放型 / 横按型（G = `320003`、F = `133211`）本来就是六音，
    「好按」不靠少按几个音来换
  - 卡片上直接摊出该和弦的**备选按法**（按易按成本从小到大），这才是「和弦表」该有的样子；
    它只保证每个和弦自己好按，**不保证整条好弹** —— 各按法之间手要来回跑
- 「把位窗口宽度」和「品格上限」两种模式都可以调，用来把搜索限制在能弹的范围内。
  两种模式都给出「手挪 ∑」方便对照：「最常见 / 最易按」这个数字通常明显大于
  「声部连接最优」，想看它小就切回模式一。

**同一个和弦的多个把位。** 模式二除「**常用按法**」（全局最省那一个）之外，
再给**低 / 中 / 高把位区各一个方案** —— 同一个和弦在不同把位上的按法可以并排比较，
方案条上一眼看得到每个方案的平均按品与手挪量。每个和弦仍各自独立选按法，
方案之间也不做配对。卡片上还标了两样：

- 「**按 X 型**」—— 这个和弦该用哪个 CAGED 型（C / A / G / E / D 或它们的升降号形态）。
- 「**可选把位：第 N 品…（共 M 种按法）**」—— 该和弦在当前窗口下所有可用按法的把位分布，
  点一下就能切过去。

**变调夹。** 两种模式顶部都有「**变调夹**」下拉（默认不夹，可夹 1–9 品）。
夹在第 N 品等于**琴枕上移 N 品**，整条进行的按法随之下移重算：
指法数字一律**相对变调夹**（0 = 就在夹子处按弦），实际发出来仍是上面写的和弦名。
夹子越低越省手指、声音越高；把「品格上限」一起调小可以避免搜索跑到夹子以上的高把位去。

## 🖐 2-1-2 琶音

弦上音数按 `2-1-2` 交替（2 音 / 1 音 / 2 音 …），**不是**「沿琴颈每弦取几个音」。
页面上有「起始弦」开关（第 6 / 5 / 4 / 3 弦）与「指型总表」。

要点：

- 最多铺到 6 弦 9 音；起始弦靠上时弦数不够会**自然截断**，这是正常的
- 只占 3 弦 5 音的那一小块叫**基本型**，是这套指型的原子单元
- **块内的取音是三度叠置的琶音，不是连续的音阶音** —— 这一点常被误解

## 🎯 和弦查询

**反过来查**：在指板上点出你按到的音（最少 3 个），反推这是个什么和弦。
**只点了 2 个音**也照给结果 —— 见本节末尾的「只点了两个音」。
这是「我手上按着这么几个音，它到底叫什么」的入口。

点一下选中、再点一下取消；右上角可以**试听已选音**，左下角能撤销一个 / 全部清空。
**点完音结果立刻出来** —— 不用再切一次页、也不用碰一下别的控件。

左侧「已选音」每行带一个**色点**（和指板上那颗音同一个颜色）、它在指板上点到的
**全部位置**（几弦几品）、一个 **×**（删掉这个音，一次删掉它的所有位置），
以及需要时的「范围外」角标 —— 位置落在当前显示范围之外时仍**照常参与匹配**，
只是标出来，免得你以为工具少算了。

两条基本规矩：

- **匹配只看音高类** —— 同一个音在高音弦、低音弦各点一次，只当一个音算。
- **低音 = 已选音里音高最低的那个位置**，不是「先点的那个」。
  图上会额外套一圈**虚线环**标出来 —— 颜色让给音高类，低音改用形状标，两个信息不打架。
- **12 个音高类各有一种颜色**：色相按**五度圈**顺序排（C → G → D → A → E → B → F♯ …），
  于是五度圈上挨着的两个音色相正好差 30°，连 E / F、B / C 这种半音邻居也能一眼分开。
  明度按色相的感知亮度分档（黄绿系压暗、蓝系提亮），让 12 个色块都压得住白字；
  深色主题共用这一套色，在深底上同样清楚。

三种匹配方式：

| 方式 | 你知道什么 | 得到什么 |
|---|---|---|
| **粗匹配** | 只知道按到了哪些音 | 枚举 12 个候选根音 × 46 条和弦性质，分「精确命中 / 加音读法 / 少音读法」三类列出 |
| **音级匹配** | 知道部分音是几音（不确定就留「不知道」） | 有几颗已知就够收敛；根音没被指定时会出现**斜线和弦** `X/Y` |
| **调内和弦** | 知道处在哪个母音阶下 | 只在该音阶的七级和弦里找（三 / 四 / 五个音都枚举），按**常见的可能性**从高到低排 |

「调内和弦」的**体系只留五个七声体系**：自然大调、和声小调、旋律小调、和声大调、双和声小调。
五声与布鲁斯、对称音阶、异域与 Bebop、琶音这些家族要么音数不是七、要么谈不上「这个调下的各级和弦」，
不在这个下拉里；选定体系后，母音阶下拉列的是该体系的**母音阶 + 它的全部调式**（母音阶排最前）。

「调内和弦」再给某几颗音标上**它在这个和弦里是第几个音**（1 音 / 3 音 / 5 音 …），
就从粗匹配进到细匹配。选「不知道」表示不约束，选「调外音」则直接排除这个音阶。

**对不上任何和弦时**，页面不会硬凑：按那套「去掉七声音阶的根音、拆成两个三音组」的体系兜底分类 ——
三和弦 / 四度叠置 / 音簇 / 七和弦缺五音 / 七和弦缺三音，五族各 4 个成员。
这颗三音组归哪一族、能和哪一族配成完整的一组，全都列出来。

### 只点了两个音

两个音的信息量不够定和弦 —— 但也足够说清**这两颗音之间的关系**。所以恰好点出 2 个音时，
页面不硬套上面三种匹配方式，而是给两条结果，各自明确写出：

| 条目 | 写什么 |
|---|---|
| **音程关系** | 从**低音往高音**数：音程名 ＋ 国际缩写 ＋ 半音数；再给一条**反向读数**（从高音数下来），两种读法互为转位 |
| **和弦** | 这两个音是否凑成一个**构成音天生只有两个**的和弦；是就写名字，不是就写「不适用」并说明为什么 |

低音取**实际音高最低的那个位置**（不是先点的那个），和斜线和弦 `X/Y` 的记法是同一条口径 ——
同一对音换个摆法，不该出现两个互相打架的说法。

通用标记里**构成音只有两个的和弦只有一个：五和弦**（强力和弦 `X5`，根音 ＋ 纯五度）。
所以一对音**两种摆法都认**：

- **7 个半音（纯五度）** —— 低音就是根音，写**原位** `C5`；
- **5 个半音（纯四度）** —— 低音落在五度上、根音在上面那颗，写**转位** `F5/C`。

其余 9 个音程（二度 / 三度 / 三全音 / 六度 / 七度）一律写「不适用」，
并说清楚「通用标记里只有五和弦是两音和弦」—— **不硬凑名字**。

这一条**只在恰好 2 个音时触发**：点满 3 个音就进上面三种匹配方式；
只点 1 个音时仍提示还差几个音，只是会多一句「点满 2 个音可以先看这两颗音的音程关系」。

## 🎼 音阶查询

**反过来查**：在指板上点出 5 个以上的音，反推这是什么音阶。

- **粗匹配** —— 在全部 82 条音阶 × 12 个主音（**984 条读法**）里找「装得下你点出的全部音」的音阶，
  按**你还差几个音**分层。点 5 个音、命中七声音阶，就是「还差 2 个音」。
- **细匹配** —— 指定主音后收敛，结果会少很多。

**同一组音往往有好几个名字**，所以一条结果不是「一个音阶」，而是**一组音**：

- 七声音阶的同一组音有 7 个读法（C 伊奥尼亚 = D 多利亚 = E 弗里吉亚 = …）
- 五声音阶有 5 个（C 大调五声 = A 小调五声 = …）
- 对称音阶更极端 —— 全音阶转 2 / 4 / 6 / 8 / 10 个半音都还是它自己

页面把**同一组音的全部读法并列**出来，每个都能点一下当主音进细匹配；
对称的那些另有一个徽标记明「连主音都分不出来，只能给出母音阶组」，交给你按上下文判断。

交互与配色跟和弦页完全一致 —— 两页用的是同一块指板、同一份已选音。
